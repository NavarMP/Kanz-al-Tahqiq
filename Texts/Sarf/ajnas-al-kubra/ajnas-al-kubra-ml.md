## ആമുഖവും ലാസിം-മുതഅദ്ദി വിഭജനവും

<div dir="rtl" lang="ar">
الْحَمْدُ لِلَّهِ رَبِّ الْعَالَمِينَ، وَالْعَاقِبَةُ لِلْمُتَّقِينَ، وَالصَّلَاةُ وَالسَّلَامُ عَلَى سَيِّدِنَا مُحَمَّدٍ، وَآلِهِ وَصَحْبِهِ أَجْمَعِينَ. وَبَعْدُ: فَاعْلَمْ يَا أَخِي -أَسْعَدَكَ اللَّهُ تَعَالَى وَإِيَّانَا فِي الدَّارَيْنِ- أَنَّ الْأَفْعَالَ مِنْ حَيْثُ الْمَعْنَى نَوْعَانِ: لَازِمٌ، وَمُتَعَدٍّ.
</div>

**വിവർത്തനവും ദർസ് വ്യാഖ്യാനവും:**  
സർവ്വലോക പരിപാലകനായ അല്ലാഹുവിന് സർവ്വസ്തുതിയും, ഭയഭക്തിയുള്ളവർക്കാണ് ശുഭപര്യവസാനം. നമ്മുടെ നേതാവായ മുഹമ്മദ് നബി ﷺ യുടെ മേലിലും അവിടുത്തെ കുടുംബത്തിന്റെയും സ്വഹാബത്തിന്റെയും മേലിലും അല്ലാഹുവിന്റെ സ്വലാത്തും സലാമും വർഷിക്കട്ടെ.  
തുടർന്ന് പറയട്ടെ: എന്റെ സഹോദരാ, നീ അറിയുക - ഇരുലോകങ്ങളിലും അല്ലാഹു നിനക്കും എനിക്കും സൗഭാഗ്യം പ്രധാനം ചെയ്യട്ടെ! - അർത്ഥ തലത്തെ മുൻനിർത്തി നോക്കുമ്പോൾ അറബിയിലെ ക്രിയകൾ രണ്ട് വിധമാണ്:
1. **ലാസിം (അകർമ്മക ക്രിയ):** കർത്താവിൽ (ഫാഇൽ) നിന്ന് കർമ്മത്തിലേക്ക് (മഫ്ഊൽ) കടക്കാത്തതും, കർത്താവിൽ മാത്രം ഒതുങ്ങിനിൽക്കുന്നതുമായ ക്രിയകൾ. ഉദാഹരണം: <span dir="rtl" lang="ar">حَسُنَ زَيْدٌ</span> (സൈദ് ഭംഗിയുള്ളവനായി), <span dir="rtl" lang="ar">قَعَدَ عَمْرٌو</span> (അംറ് ഇരുന്നു). ഇതിൽ നിന്ന് സാക്ഷാൽ മജ്ഹൂലോ ഇസ്മുൽ മഫ്ഊലോ ഉണ്ടാക്കപ്പെടുകയില്ല (ഒരു പ്രിപ്പോസിഷന്റെയും മജ്റൂറിന്റെയും സഹായത്തോടെയല്ലാതെ).
2. **മുതഅദ്ദി (സകർമ്മക ക്രിയ):** കർത്താവിനെ വിട്ട് ജർറിന്റെ അക്ഷരങ്ങളുടെ സഹായമില്ലാതെ നേരിട്ട് മഫ്ഊലിലേക്ക് ബന്ധം വ്യാപിക്കുന്ന ക്രിയകൾ. ഉദാഹരണം: <span dir="rtl" lang="ar">ضَرَبَ زَيْدٌ عَمْرًا</span> (സൈദ് അംറിനെ അടിച്ചു). ഇതിൽ നിന്ന് മഅ്‌ലൂമും മജ്ഹൂലും ഇസ്മുൽ ഫാഇലും ഇസ്മുൽ മഫ്ഊലും ഉണ്ടാക്കപ്പെടും.

## ഒന്നാം അധ്യായം: മുജർറദായ മൂന്നക്ഷര ക്രിയകളും ആറ് ബാബുകളും

അറബി ഭാഷയിലെ മുജർറദായ മൂന്നക്ഷര ക്രിയകളുടെ മാളിയിലെയും മുളാരിഇലെയും ഐൻ അക്ഷരത്തിന്റെ ഹറകത്തുകൾ പരിശോധിച്ച് നോക്കുമ്പോൾ അവ ആറ് ബാബുകളിലായി പരിമിതപ്പെട്ടിരിക്കുന്നു:

1. **ഒന്നാം ബാബ്: ഫതഹു ളംമ് (فَتْحُ ضَمٍّ - ഫഅല യഫ്ഉലു):**  
   - മാതൃക: നസ്വറ യൻസ്വുറു (نَصَرَ يَنْصُرُ). സാധാരണയായി മുതഅദ്ദിയായും അപൂർവ്വമായി ലാസിമായും വരുന്നു (ഖഅദ യഖ്ഉദു പോലെ).
2. **രണ്ടാം ബാബ്: ഫതഹു കസ്റ് (فَتْحُ كَسْرٍ - ഫഅല യഫ്ഇലു):**  
   - മാതൃക: ളറബ യള്‌രിബു (ضَرَبَ يَضْرِبُ). സാധാരണ മുതഅദ്ദിയായും അപൂർവ്വമായി ലാസിമായും വരുന്നു (ജലസ യജ്‌ലിസു പോലെ).
3. **മൂന്നാം ബാബ്: ഫതഹത്താനി (فَتْحَتَانِ - ഫഅല യഫ്അലു):**  
   - മാതൃക: ഫതഹ യഫ്തഹു (فَتَحَ يَفْتَحُ). ഇതിന്റെ ഐനോ ലാമോ തൊണ്ടയുടെ അക്ഷരങ്ങളിലൊന്നാവൽ നിബന്ധനയാണ്.
4. **നാലാം ബാബ്: കസ്റു ഫതഹ് (كَسْرُ فَتْحٍ - ഫഇല യഫ്അലു):**  
   - മാതൃക: അലിമ യഅ്‌ലമു (عَلِمَ يَعْلَمُ). മുതഅദ്ദിയായും ലാസിമായും വരുന്നു (ഫരിഹ യഫ്റഹു പോലെ).
5. **അഞ്ചാം ബാബ്: ളംമു ളംമ് (ضَمُّ ضَمٍّ - ഫഉല യഫ്ഉലു):**  
   - മാതൃക: കറുമ യക്റുമു (كَرُمَ يَكْرُمُ). പ്രകൃതിപരമായ സ്വഭാവങ്ങൾക്കായതുകൊണ്ട് ഇത് എല്ലായ്പ്പോഴും ലാസിം മാത്രമായിരിക്കും.
6. **ആറാം ബാബ്: കസ്റത്താനി (كَسْرَتَانِ - ഫഇല യഫ്ഇലു):**  
   - മാതൃക: ഹസിബ യഹ്സിബു (حَسِبَ يَحْسِبُ). ഏറ്റവും ചുരുങ്ങിയ രൂപങ്ങളിൽ മാത്രമാണ് ഇത് പ്രയോഗിക്കപ്പെടുന്നത്.

## രണ്ടാം അധ്യായം: ശാദ്ദായ (അപൂർവ്വ) ക്രിയകൾ

പൊതുവായ ഖിയാസിന് വിരുദ്ധമായി അറബികളിൽ നിന്ന് കേൾക്കപ്പെട്ടവയാണ് ശാദ്ദായ ക്രിയകൾ:
- തൊണ്ടയുടെ അക്ഷരമില്ലാതെ മൂന്നാം ബാബിൽ വന്നത്: <span dir="rtl" lang="ar">أَبَى يَأْبَى</span> (അബാ യഅ്ബാ - വിസമ്മതിച്ചു). ഇതിൽ ഹംസ ഫാഅ് ആണ്, ഐനോ ലാമോ അല്ല.
- മാളിയിലും മുളാരിഇലും കസ്റ് വന്ന മുഅ്തല്ലായ ക്രിയകൾ: വമിഖ യമിഖു (വിലമതിച്ചു), വരിഥ യരിഥു (അനന്തരമെടുത്തു), വലിയ്യ യലീ (ഭരണം നടത്തി), വഥിഖ യഥിഖു (വിശ്വസിച്ചു).

## മൂന്നാം അധ്യായം: ഇരുപത് തരം തസ്‌രീഫ് രൂപങ്ങൾ

ഒന്നാം ബാബായ നസ്വറ യൻസ്വുറു വിന്റെ ഉദാഹരണത്തിൽ പൂർണ്ണ തസ്‌രീഫ് ചങ്ങല:
1. മാളി മഅ്‌ലൂം: <span dir="rtl" lang="ar">نَصَرَ</span> (സഹായിച്ചു).
2. മുളാരിഅ് മഅ്‌ലൂം: <span dir="rtl" lang="ar">يَنْصُرُ</span> (സഹായിക്കുന്നു).
3. മസ്ദർ: <span dir="rtl" lang="ar">نَصْرًا</span> (സഹായം).
4. ഇസ്മുൽ ഫാഇൽ: <span dir="rtl" lang="ar">نَاصِرٌ</span> (സഹായിച്ചവൻ).
5. മാളി മജ്ഹൂൽ: <span dir="rtl" lang="ar">نُصِرَ</span> (സഹായിക്കപ്പെട്ടു).
6. മുളാരിഅ് മജ്ഹൂൽ: <span dir="rtl" lang="ar">يُنْصَرُ</span> (സഹായിക്കപ്പെടുന്നു).
7. ഇസ്മുൽ മഫ്ഊൽ: <span dir="rtl" lang="ar">مَنْصُورٌ</span> (സഹായിക്കപ്പെട്ടവൻ).
8. ലം കൊണ്ടുള്ള ജഹ്ദ്: <span dir="rtl" lang="ar">لَمْ يَنْصُرْ</span> (സഹായിച്ചിട്ടില്ല).
9. ലാ കൊണ്ടുള്ള നഫി: <span dir="rtl" lang="ar">لَا يَنْصُرُ</span> (സഹായിക്കുന്നില്ല).
10. ലൻ കൊണ്ടുള്ള നഫി: <span dir="rtl" lang="ar">لَنْ يَنْصُرَ</span> (ഒരിക്കലും സഹായിക്കുകയില്ല).
11. അംറുൽ ഗാഇബ്: <span dir="rtl" lang="ar">لِيَنْصُرْ</span> (അവൻ സഹായിക്കട്ടെ).
12. അംറുൽ ഹാളിർ: <span dir="rtl" lang="ar">انْصُرْ</span> (നീ സഹായിക്കൂ).
13. നഹ്‌യുൽ ഗാഇബ്: <span dir="rtl" lang="ar">لَا يَنْصُرْ</span> (അവൻ സഹായിക്കരുത്).
14. നഹ്‌യുൽ ഹാളിർ: <span dir="rtl" lang="ar">لَا تَنْصُرْ</span> (നീ സഹായിക്കരുത്).
15. തൗകീദിന്റെ സഖീലയായ നൂൻ: <span dir="rtl" lang="ar">لَيَنْصُرَنَّ / انْصُرَنَّ</span> (തീർച്ചയായും സഹായിക്കണം).
16. തൗകീദിന്റെ ഖഫീഫയായ നൂൻ: <span dir="rtl" lang="ar">لَيَنْصُرَنْ / انْصُرَنْ</span>.
17. ഇസ്മുസ്സിമാൻ-മകാൻ: <span dir="rtl" lang="ar">مَنْصَرٌ</span> (സഹായ സമയം / സ്ഥലം).
18. ഇസ്മുൽ ആലഃ: <span dir="rtl" lang="ar">مِنْصَرٌ</span> (സഹായ ഉപകരണം).
19. ഇസ്മുൽ മർറഃ: <span dir="rtl" lang="ar">نَصْرَةً</span> (ഒരൊറ്റ സഹായം).
20. ഇസ്മുൽ ഹൈഅഃ: <span dir="rtl" lang="ar">نِصْرَةً</span> (സഹായത്തിന്റെ രീതി).

## നാലാം അധ്യായം: മസീദായ മൂന്നക്ഷര ക്രിയകളും അവയുടെ ആശയങ്ങളും

അധികാക്ഷരങ്ങൾ ചേരുമ്പോൾ പദങ്ങളുടെ ആശയത്തിൽ മാറ്റം വരുന്നു («സിയാദതുൽ മബ്നാ തദുല്ലു അലാ സിയാദതിൽ മഅ്നാ»):
1. **അഫ്അല (إِفْعَال):** തഅ്ദിയ്യത്ത് (ലാസിമിനെ മുതഅദ്ദിയാക്കൽ - അഖാമ സൈദൻ), സമയത്തോ സ്ഥലത്തോ പ്രവേശിക്കൽ (അസ്വ്ബഹ, അഅ്റഖ), നീക്കിക്കളയൽ (അഅ്ജമൽ കിതാബ).
2. **ഫഅ്അല (تَفْعِيل):** അധികരിപ്പിക്കൽ (ഖത്വഅ - കഷ്ണങ്ങളാക്കി), തഅ്ദിയ്യത്ത് (ഫർറഹ), ഒരു സ്വഭാവത്തിലേക്ക് ചേർക്കൽ (ഫസ്സഖ, കഫ്ഫറ).
3. **ഫാഅല (مُفَاعَلَة):** പങ്കാളിത്തം (ഖാത്തല - ഇരുവിഭാഗങ്ങൾ തമ്മിൽ യുദ്ധം ചെയ്യൽ).
4. **ഇൻഫഅല (انْفِعَال):** മുത്വവഅത്ത് (കർമ്മം മാറ്റത്തെ സ്വീകരിക്കൽ - ഇൻകസറ), ഇത് ലാസിം മാത്രമായിരിക്കും.
5. **ഇഫ്തഅല (افْتِعَال):** അദ്ധ്വാനം, സ്വയം ഉണ്ടാക്കൽ (ഇക്തസബ, ഇജ്തമഅ).
6. **ഇസ്തിഫ്അൽ (اسْتِفْعَال):** ആവശ്യം തേടൽ (ഇസ്തഗ്ഫറ - പൊറുക്കലിനെ തേടി), ആയിത്തീരൽ (ഇസ്തഹ്ജറ - കല്ലായി മാറി).
