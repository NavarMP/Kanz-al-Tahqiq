| الصِّيغَةُ الصَّرْفِيَّةُ | الْمُذَكَّرُ | الْمُؤَنَّثُ |
|---|---|---|
| **الْمَاضِي الْمَعْلُومُ (الْمُفْرَدُ)** | ضَرَبَ | ضَرَبَتْ |
| **الْمَاضِي الْمَعْلُومُ (الْمُثَنَّى)** | ضَرَبَا | ضَرَبَتَا |
| **الْمَاضِي الْمَعْلُومُ (الْجَمْعُ)** | ضَرَبُوا | ضَرَبْنَ |
| **الْمُضَارِعُ الْمَعْلُومُ (الْمُفْرَدُ)** | يَضْرِبُ | تَضْرِبُ |
| **الْمُضَارِعُ الْمَعْلُومُ (الْمُثَنَّى)** | يَضْرِبَانِ | تَضْرِبَانِ |
| **الْمُضَارِعُ الْمَعْلُومُ (الْجَمْعُ)** | يَضْرِبُونَ | يَضْرِبْنَ |
| **الْمَاضِي الْمَجْهُولُ (الْمُفْرَدُ)** | ضُرِبَ | ضُرِبَتْ |
| **الْمُضَارِعُ الْمَجْهُولُ (الْمُفْرَدُ)** | يُضْرَبُ | تُضْرَبُ |
| **اسْمُ الْفَاعِلِ** | ضَارِبٌ (مُثَنَّى: ضَارِبَانِ، جَمْعٌ: ضَارِبُونَ) | ضَارِبَةٌ (مُثَنَّى: ضَارِبَتَانِ، جَمْعٌ: ضَارِبَاتٌ) |
| **اسْمُ الْمَفْعُولِ** | مَضْرُوبٌ (مُثَنَّى: مَضْرُوبَانِ، جَمْعٌ: مَضْرُوبُونَ) | مَضْرُوبَةٌ (مُثَنَّى: مَضْرُوبَتَانِ، جَمْعٌ: مَضْرُوبَاتٌ) |
| **أَمْرُ الْمُخَاطَبِ (الْحَاضِرِ)** | اضْرِبْ (مُثَنَّى: اضْرِبَا، جَمْعٌ: اضْرِبُوا) | اضْرِبِي (مُثَنَّى: اضْرِبَا، جَمْعٌ: اضْرِبْنَ) |
| **نَهْيُ الْمُخَاطَبِ (الْحَاضِرِ)** | لَا تَضْرِبْ (مُثَنَّى: لَا تَضْرِبَا، جَمْعٌ: لَا تَضْرِبُوا) | لَا تَضْرِبِي (مُثَنَّى: لَا تَضْرِبَا، جَمْعٌ: لَا تَضْرِبْنَ) |
