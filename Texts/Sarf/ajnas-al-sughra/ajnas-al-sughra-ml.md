# കിതാബുൽ അജ്നാസിസ്സ്വുഗ്റാ (كتاب الأجناس الصغرى)
### ദർസ് പാഠ്യപദ്ധതിക്കായുള്ള വിശദമായ മലയാള വിവർത്തനവും വ്യാഖ്യാനവും
*ഗ്രന്ഥകർത്താവ്: അല്ലാമ ദാദാ അലി ബിൻ ശൈഖ് ഖാസിം (വഫാത്ത്: 1127 ഹിജ്റ / 1715 ക്രി)*  
*വിഷയം: ഇൽമുസ്സ്വർഫ് (അറബിക് മോർഫോളജി) · കൻസ് അത്തഹ്ഖീഖ് ലൈബ്രറി*

- [മൂന്നാം ഭാഗം: റുബാഇ മുജർറദും മുൽഹഖാത്തും മസീദും](#മൂന്നാം-ഭാഗം-റുബാഇ-മുജർറദും-മുൽഹഖാത്തും-മസീദും)
- [നാലാം ഭാഗം: അഖ്സാമുസ്സബ്അഃ (ഏഴ് തരം ക്രിയകൾ)](#നാലാം-ഭാഗം-അഖ്സാമുസ്സബ്അഃ-ഏഴ്-തരം-ക്രിയകൾ)

## ആമുഖം: ക്രിയകളുടെ വർഗ്ഗീകരണം (അജ്നാസുൽ അഫ്ആൽ)

<div dir="rtl" lang="ar">
فَصْلٌ: فِي أَجْنَاسِ الْأَفْعَالِ: اعْلَمْ أَنَّ الْأَفْعَالَ: إِمَّا ثُلَاثِيٌّ، وَإِمَّا رُبَاعِيٌّ. وَكُلُّ وَاحِدٍ مِنْهُمَا: إِمَّا مُجَرَّدٌ، أَوْ مَزِيدٌ فِيهِ.
</div>

**വിവർത്തനവും ആശയവും:**  
ക്രിയകളുടെ വംശങ്ങളെയും ഇനങ്ങളെയും വ്യക്തമാക്കുന്ന അധ്യായം:  
നീ അറിയുക: തീർച്ചയായും അറബി ഭാഷയിലെ ക്രിയകൾ (അടിസ്ഥാന അക്ഷരങ്ങളുടെ എണ്ണമനുസരിച്ച്) ഒന്നുകിൽ **ഥുലാഥീ (മൂന്നക്ഷരമുള്ളവ)** ആയിരിക്കും, അല്ലെങ്കിൽ **റുബാഈ (നാലക്ഷരമുള്ളവ)** ആയിരിക്കും. ഇവ ഓരോന്നും ഒന്നുകിൽ **മുജർറദ് (അധികാക്ഷരമില്ലാത്ത അടിസ്ഥാന ക്രിയകൾ)** ആയിരിക്കും, അല്ലെങ്കിൽ **മസീദ് ഫീഹ് (അധികാക്ഷരങ്ങൾ ചേർത്തവ)** ആയിരിക്കും.

---

## ഒന്നാം ഭാഗം: മുജർറദായ മൂന്നക്ഷര ക്രിയകൾ (അഞ്ച് ബാബുകൾ)

മുജർറദായ മൂന്നക്ഷര ക്രിയകൾ അഞ്ച് ബാബുകളിലായാണ് ക്രമീകരിച്ചിരിക്കുന്നത്:

### 1. ഒന്നാം ബാബ്: ഫഅല - യഫ്ഇലു (فَعَلَ - يَفْعِلُ)
- **മാതൃകാ ക്രിയ:** ളറബ - യള്‌രിബു (ضَرَبَ - يَضْرِبُ - അടിച്ചവൻ / അടിക്കുന്നു).
- **സൂത്രവാക്യം:**
  - മാളി: <span dir="rtl" lang="ar">ضَرَبَ</span> (ളറബ)
  - മുളാരിഅ്: <span dir="rtl" lang="ar">يَضْرِبُ</span> (യള്‌രിബു)
  - മസ്ദർ: <span dir="rtl" lang="ar">ضَرْبًا</span> (ളർബൻ)
  - ഇസ്മുൽ ഫാഇൽ: <span dir="rtl" lang="ar">ضَارِبٌ</span> (ളാരിബുൻ - അടിച്ചവൻ)
  - മജ്ഹൂലായ മാളി: <span dir="rtl" lang="ar">ضُرِبَ</span> (ളുരിബ - അടിക്കപ്പെട്ടു)
  - മജ്ഹൂലായ മുളാരിഅ്: <span dir="rtl" lang="ar">يُضْرَبُ</span> (യുള്‌റബു - അടിക്കപ്പെടുന്നു)
  - ഇസ്മുൽ മഫ്ഊൽ: <span dir="rtl" lang="ar">مَضْرُوبٌ</span> (മള്‌റൂബുൻ - അടിക്കപ്പെട്ടവൻ)
  - അംറ് (കൽപ്പന): <span dir="rtl" lang="ar">اضْرِبْ</span> (ഇള്‌രിബ് - അടിക്കൂ)
  - നഹ്‌യ് (വിരോധന): <span dir="rtl" lang="ar">لَا تَضْرِبْ</span> (ലാ തള്‌രിബ് - അടിക്കരുത്)

### 2. രണ്ടാം ബാബ്: ഫഅല - യഫ്ഉലു (فَعَلَ - يَفْعُلُ)
- **മാതൃകാ ക്രിയ:** നസ്വറ - യൻസ്വുറു (نَصَرَ - يَنْصُرُ - സഹായിച്ചവൻ / സഹായിക്കുന്നു).
- അംറ്: <span dir="rtl" lang="ar">انْصُرْ</span> (ഉൻസ്വുർ), നഹ്‌യ്: <span dir="rtl" lang="ar">لَا تَنْصُرْ</span> (ലാ തൻസ്വുർ).

### 3. മൂന്നാം ബാബ്: ഫഅല - യഫ്അലു (فَعَلَ - يَفْعَلُ)
- **മാതൃകാ ക്രിയ:** ഫതഹ - യഫ്തഹു (فَتَحَ - يَفْتَحُ - തുറന്നവൻ / തുറക്കുന്നു).
- ഈ ബാബിലെ ക്രിയകളുടെ ഐനോ ലാമോ തൊണ്ടയുടെ അക്ഷരങ്ങളിൽ (ഹുറൂഫുൽ ഹൽഖ്) ഒന്നായിരിക്കണം.
- അംറ്: <span dir="rtl" lang="ar">افْتَحْ</span> (ഇഫ്തഹ്), നഹ്‌യ്: <span dir="rtl" lang="ar">لَا تَفْتَحْ</span> (ലാ തഫ്തഹ്).

### 4. നാലാം ബാബ്: ഫഇല - യഫ്അലു (فَعِلَ - يَفْعَلُ)
- **മാതൃകാ ക്രിയ:** സമിഅ - യസ്മഉ (سَمِعَ - يَسْمَعُ - കേട്ടവൻ / കേൾക്കുന്നു).
- അംറ്: <span dir="rtl" lang="ar">اسْمَعْ</span> (ഇസ്മഅ്), നഹ്‌യ്: <span dir="rtl" lang="ar">لَا تَسْمَعْ</span> (ലാ തസ്മഅ്).

### 5. അഞ്ചാം ബാബ്: ഫഉല - യഫ്ഉലു (فَعُلَ - يَفْعُلُ)
- **മാതൃകാ ക്രിയ:** കറുമ - യക്റുമു (كَرُمَ - يَكْرُمُ - ഉദാരനായവൻ / ഉദാരനാവുന്നു).
- ഈ ബാബ് പ്രകൃതിപരമായ ഗുണവിശേഷങ്ങൾക്കും സഭാവങ്ങൾക്കും വേണ്ടി നിശ്ചയിക്കപ്പെട്ടതായതുകൊണ്ട് ഇത് എല്ലായ്പ്പോഴും **ലാസിം (അകർമ്മകം)** മാത്രമായിരിക്കും. ഇതിൽ നിന്ന് മജ്ഹൂലോ ഇസ്മുൽ മഫ്ഊലോ ഉണ്ടാക്കപ്പെടുകയില്ല.
- അംറ്: <span dir="rtl" lang="ar">اكْرُمْ</span> (ഉക്രും), നഹ്‌യ്: <span dir="rtl" lang="ar">لَا تَكْرُمْ</span> (ലാ തക്രും).

## രണ്ടാം ഭാഗം: മസീദായ മൂന്നക്ഷര ക്രിയകൾ (14 ബാബുകൾ)

മൂന്ന് അക്ഷരങ്ങളുള്ള ക്രിയകളിലേക്ക് അധികാക്ഷരങ്ങൾ ചേരുമ്പോൾ അവയെ മൂന്ന് ഇനങ്ങളായി തിരിക്കുന്നു:

1. **ഒരക്ഷരം അധികരിപ്പിച്ചവ (3 ബാബുകൾ):**
   - **ഇഫ്ആൽ:** <span dir="rtl" lang="ar">أَكْرَمَ يُكْرِمُ إِكْرَامًا</span> (അക്‌റമ - ആദരിച്ചു).
   - **തഫ്ഈൽ:** <span dir="rtl" lang="ar">فَرَّحَ يُفَرِّحُ تَفْرِيحًا</span> (ഫർറഹ - സന്തോഷിപ്പിച്ചു).
   - **മുഫാഅലഃ:** <span dir="rtl" lang="ar">قَاتَلَ يُقَاتِلُ مُقَاتَلَةً</span> (ഖാത്തല - യുദ്ധം ചെയ്തു).
2. **രണ്ടക്ഷരങ്ങൾ അധികരിപ്പിച്ചവ (5 ബാബുകൾ):**
   - **ഇൻഫിആൽ:** <span dir="rtl" lang="ar">انْكَسَرَ يَنْكَسِرُ</span> (ഇൻകസറ - ഉടഞ്ഞു).
   - **ഇഫ്തിആൽ:** <span dir="rtl" lang="ar">اجْتَمَعَ يَجْتَمِعُ</span> (ഇജ്തമഅ - ഒത്തുചേർന്നു).
   - **ഇഫ്ഇലാൽ:** <span dir="rtl" lang="ar">احْمَرَّ يَحْمَرُّ</span> (ഇഹ്മർറ - ചുവന്നു).
   - **തഫഅ്ഉൽ:** <span dir="rtl" lang="ar">تَعَلَّمَ يَتَعَلَّمُ</span> (തഅല്ലമ - പഠിച്ചു).
   - **തഫാഉൽ:** <span dir="rtl" lang="ar">تَبَاعَدَ يَتَبَاعَدُ</span> (തബാഅദ - അകന്നുനിന്നു).
3. **മൂന്നക്ഷരങ്ങൾ അധികരിപ്പിച്ചവ (6 ബാബുകൾ):**
   - **ഇസ്തിഫ്ആൽ:** <span dir="rtl" lang="ar">اسْتَخْرَجَ يَسْتَخْرِجُ</span> (ഇസ്തഖ്റജ - പുറത്തെടുത്തു).
   - **ഇഫ്ഈആൽ:** <span dir="rtl" lang="ar">اعْشَوْشَبَ يَعْشَوْشِبُ</span> (ഇഅ്ശൗശബ - പുല്ലുനിറഞ്ഞു).
   - **ഇഫ്ഇവ്വാൽ:** <span dir="rtl" lang="ar">اجْلَوَّذَ يَجْلَوِّذُ</span> (ഇജ്‌ലവ്വദ - വേഗത്തിൽ സഞ്ചരിച്ചു).
   - **ഇഫ്ഈലാൽ:** <span dir="rtl" lang="ar">احْمَارَّ يَحْمَارُّ</span> (ഇഹ്മാ balance - അത്യധികം ചുവന്നു).

## മൂന്നാം ഭാഗം: റുബാഇ മുജർറദും മുൽഹഖാത്തും മസീദും

1. **റുബാഇ മുജർറദ്:**  
   നാല് അടിസ്ഥാന അക്ഷരങ്ങളുള്ള ക്രിയ ഒരൊറ്റ ബാബ് മാത്രമാണ്: <span dir="rtl" lang="ar">فَعْلَلَ يُفَعْلِلُ</span> (ദഹ്റജ യുദഹ്‌രിജു - ഉരുട്ടി / ഉരുട്ടുന്നു).
2. **മുൽഹഖാത്ത് (റുബാഇയോട് ചേർത്തപ്പെട്ടവ):**  
   ദഹ്റജയുടെ അതേ വസ്‌നിലാവാനായി ഒരക്ഷരം അധികരിപ്പിച്ചവ: ഹൗഖല (فَوْعَلَ), ജഹ്‌വറ (فَعْوَلَ), ബൈത്വറ (فَيْعَلَ), അഥ്‌യറ (فَعْيَلَ), ജൽബബ (فَعْلَلَ), സൽഖാ (فَعْلَى).
3. **റുബാഇ മസീദ്:**
   - ഒരക്ഷരം അധികരിപ്പിച്ചത്: <span dir="rtl" lang="ar">تَفَعْلَلَ</span> (തദഹ്‌റജ - സ്വയം ഉരുണ്ടു).
   - രണ്ടക്ഷരങ്ങൾ അധികരിപ്പിച്ചവ: <span dir="rtl" lang="ar">افْعَنْلَلَ</span> (ഇഹ്‌റൻജമ - ഒത്തുകൂടി), <span dir="rtl" lang="ar">افْعَلَلَّ</span> (ഇഖ്ശഅർറ - രോമാഞ്ചമുണ്ടായി).

---

## നാലാം ഭാഗം: അഖ്സാമുസ്സബ്അഃ (ഏഴ് തരം ക്രിയകൾ)

അക്ഷരങ്ങളുടെ ഘടനയനുസരിച്ച് ക്രിയകളെ ഏഴായി തിരിക്കുന്നു:
1. **സ്വഹീഹ് (الصَّحِيحُ):** ഇൽലതിന്റെ അക്ഷരങ്ങളോ ഹംസയോ ഇരട്ടിപ്പോ ഇല്ലാത്തത് (ഉദാ: നസ്വറ, ളറബ).
2. **മിഥാൽ (الْمِثَالُ):** ആദ്യ അക്ഷരം (ഫാഅ്) ഇൽലത്തായത് (ഉദാ: വഅദ, യസറ).
3. **അജ്‌വഫ് (الْأَجْوَفُ):** നടുവിലെ അക്ഷരം (ഐൻ) ഇൽലത്തായത് (ഉദാ: ഖാല, ബാഅ).
4. **നാഖിസ് (النَّاقِصُ):** അവസാന അക്ഷരം (ലാം) ഇൽലത്തായത് (ഉദാ: ദആ, റമാ).
5. **ലഫീഫ് മഫ്റൂഖ് (اللَّفِيفُ الْمَفْرُوقُ):** ഒന്നും മൂന്നും അക്ഷരങ്ങൾ ഇൽലത്തായി ഇടയിൽ സ്വഹീഹായ അക്ഷരം വന്നത് (ഉദാ: വഖാ, വഫാ).
6. **ലഫീഫ് മഖ്റൂൻ (اللَّفِيفُ الْمَقْرُونُ):** രണ്ടും മൂന്നും അക്ഷരങ്ങൾ തുടർച്ചയായി ഇൽലത്തായത് (ഉദാ: ത്വവാ, ശവാ).
7. **മുളാഅഫ് (الْمُضَاعَفُ):** ഒരേ വർഗ്ഗത്തിലുള്ള രണ്ട് അക്ഷരങ്ങൾ ഒന്നിച്ചുവന്നത് (ഉദാ: മദ്ദ, ഫർറ).
