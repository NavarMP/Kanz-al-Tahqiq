# 📿 بَابُ الرَّوَاتِبِ الكُبْرَى المُسْنَدَةِ
### Canonical Transmitted Litanies (Ratibs) · رَوَاتِبُ الأَئِمَّةِ فِي حَضْرَمَوْتَ وَمَلِيبَارَ
#### خزانة الأذكار والأوراد | كنز التحقيق (Kanz al-Taḥqīq Archive)

> **﴿وَالذَّاكِرِينَ اللَّهَ كَثِيرًا وَالذَّاكِرَاتِ أَعَدَّ اللَّهُ لَهُم مَّغْفِرَةً وَأَجْرًا عَظِيمًا﴾** [[سورة الأحزاب: 35](https://quran.com/33/35)]
