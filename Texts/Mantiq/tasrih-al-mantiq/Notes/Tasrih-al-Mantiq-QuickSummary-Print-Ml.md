## 1. അറിവ് (العلم): തസവ്വുറും തസ്ദീഖും

<div class="grid-2">
  <div class="rule-box">
    <strong>തസവ്വുർ (التصور):</strong> ഒരു വിധിയില്ലാതെ മനസ്സ് ഒരു അർത്ഥം മാത്രം ഗ്രഹിക്കൽ (ഉദാ: «മനുഷ്യൻ», «സൂര്യൻ»).<br/>
    • <strong>ബദീഹി:</strong> ചിന്തയില്ലാതെ സ്വതവേ അറിയുന്നത് (ചൂട്, തണുപ്പ്).<br/>
    • <strong>നളരി:</strong> ചിന്തയും നിർവചനവും ആവശ്യമുള്ളത് (റൂഹ്, ജിന്ന്, മലക്ക്).
  </div>
  <div class="rule-box">
    <strong>തസ്ദീഖ് (التصديق):</strong> ഒരു കാര്യം മറ്റൊന്നിൽ ഉണ്ടെന്നോ ഇല്ലെന്നോ വിധിക്കൽ (ഖബരിയ്യ വിധി).<br/>
    • <strong>ബദീഹി:</strong> തെളിവില്ലാതെ സ്വതവേ ബോധ്യപ്പെടുന്നത് (ഒന്നിനേക്കാൾ വലുതാണ് രണ്ട്).<br/>
    • <strong>നളരി:</strong> ചിന്തയും തെളിവും ആവശ്യമുള്ള വിധി (പ്രപഞ്ചം ഉണ്ടായതാണ് - <span class="ar">العالم حادث</span>).
  </div>
</div>

## 2. ദലാലത്തുകൾ (الدلالات الست)
> **നിർവചനം:** ഒരു കാര്യം അറിയുന്നത് മറ്റൊന്ന് അറിയുന്നതിലേക്ക് അനിവാര്യമായി നയിക്കുന്ന അവസ്ഥ (<span class="ar">كون الشيء بحالة يلزم من العلم به العلم بشيء آخر</span>).

| ഇനം | വദ്ഇയ്യ (وضـعية) | ത്വബീഇയ്യ (طبعـية) | അഖ്‌ലിയ്യ (عقلـية) |
| :--- | :--- | :--- | :--- |
| **ലഫ്ളിയ്യ (لفظية)**<br/><small>ശബ്ദരൂപത്തിലുള്ളത്</small> | ഭാഷാ പദങ്ങൾ അർത്ഥത്തെ സൂചിപ്പിക്കൽ.<br/>ഉദാ: <span class="ar">«إنسان»</span> $\rightarrow$ ബുദ്ധിയുള്ള ജീവി | പ്രകൃതിജന്യ ശബ്ദം അവസ്ഥയെ സൂചിപ്പിക്കൽ.<br/>ഉദാ: <span class="ar">«أَخْ أَخْ»</span> $\rightarrow$ നെഞ്ചുവേദന | ശബ്ദം സംസാരിക്കുന്ന ഒരാളെ സൂചിപ്പിക്കൽ.<br/>ഉദാ: ചുമരിന് പിന്നിൽ നിന്നുള്ള ശബ്ദം |
| **ഗൈർ ലഫ്ളിയ്യ (غير لفظية)**<br/><small>ശബ്ദമല്ലാത്തത്</small> | ചിഹ്നങ്ങൾ അർത്ഥത്തെ സൂചിപ്പിക്കൽ.<br/>ഉദാ: ട്രാഫിക് റെഡ് ലൈറ്റ് $\rightarrow$ നിർത്തുക | ശരീരപ്രകൃതിയിലെ മാറ്റം സൂചിപ്പിക്കൽ.<br/>ഉദാ: മുഖം ചുവക്കൽ $\rightarrow$ ലജ്ജ, നാഡി $\rightarrow$ പനി | കാര്യം കാരണത്തെ യുക്തിപൂർവ്വം സൂചിപ്പിക്കൽ.<br/>ഉദാ: പുക $\rightarrow$ തീ; സൃഷ്ടി $\rightarrow$ സ്രഷ്ടാവ് |

<div class="rule-box">
  <strong>മന്തിഖിൽ പരിഗണിക്കുന്ന വദ്ഇയ്യ ലഫ്ളിയ്യയുടെ 3 ഇനങ്ങൾ:</strong><br/>
  1. <strong>മുതാബഖത്ത് (المطابقة):</strong> നിശ്ചയിച്ച പൂർണ്ണ അർത്ഥത്തെ സൂചിപ്പിക്കൽ (ഉദാ: «മനുഷ്യൻ» $\rightarrow$ ചിന്തിക്കുന്ന ജീവി).<br/>
  2. <strong>തദമ്മുൻ (التضمن):</strong> നിശ്ചയിച്ച അർത്ഥത്തിന്റെ ആന്തരിക ഭാഗത്തെ സൂചിപ്പിക്കൽ (ഉദാ: «മനുഷ്യൻ» $\rightarrow$ ജീവി മാത്രം / ചിന്തിക്കുന്നവൻ മാത്രം).<br/>
  3. <strong>ഇൽതിസാം (الالتزام):</strong> ബാഹ്യമായ അവിഭാജ്യ അനുബന്ധ ഗുണത്തെ സൂചിപ്പിക്കൽ (ഉദാ: «മനുഷ്യൻ» $\rightarrow$ എഴുത്ത്, ചിരി).
</div>

## 3. അൽഫാള് (الألفاظ): പദങ്ങളുടെ വിഭജനം

| പദം | ഉപവിഭാഗം | നിയമം / നിർവചനം | ഉദാഹരണം |
| :--- | :--- | :--- | :--- |
| **മുറക്കബ് (مركب)**<br/><small>ഭാഗം അർത്ഥത്തെ സൂചിപ്പിക്കുന്നത്</small> | **താം (تام)** | സംസാരം പൂർണ്ണമാവുന്നത്. **1. ഖബർ (خبر):** സത്യ/അസത്യ സാധ്യതയുള്ളത്. **2. ഇൻശാഅ് (إنشاء):** സത്യ/അസത്യ സാധ്യതയില്ലാത്തത് (അംറ്, നഹ്‌യ്, ഇസ്തിഫ്ഹാം). | ഖബർ: «സൈദ് നിൽക്കുന്നു»<br/>ഇൻശാഅ്: «വായിക്കുക!», «കളവ് പറയരുത്» |
| | **നാഖിസ് (ناقص)** | സംസാരം പൂർണ്ണമാവാത്തത്: തഖ്‌യീദി (വസ്വഫി: «വിവേകമുള്ള ജീവി», ഇദാഫി: «സൈദിന്റെ അടിമ»), ഗൈർ തഖ്‌യീദി («വീട്ടിൽ»). | «നീതിമാനായ ഭരണാധികാരി» |
| **മുഫ്രദ് (مفرد)**<br/><small>ഭാഗം അർത്ഥത്തെ സൂചിപ്പിക്കാത്തത്</small> | **ഇസ്മ് (اسم)** | സ്വതന്ത്ര അർത്ഥമുള്ളതും കാലം സൂചിപ്പിക്കാത്തതുമായ പദം (മൗദൂഉം മഹ്മൂലുമാകാം). | സൈദ്, മനുഷ്യൻ, വൃക്ഷം |
| | **കലിമ / ഫില് (كلمة)** | സ്വതന്ത്ര അർത്ഥവും കാലവുമുള്ള പദം (മഹ്മൂൽ മാത്രമേ ആകാൻ കഴിയൂ). | നിന്നു (<span class="ar">قام</span>), എഴുതുന്നു (<span class="ar">يكتب</span>) |
| | **അദാത്ത് / ഹർഫ് (أداة)** | മറ്റു പദങ്ങളുമായി ചേരുമ്പോൾ മാത്രം അർത്ഥം നൽകുന്ന പദം (റാബിത്വയായി വരുന്നു). | «-ൽ» (<span class="ar">في</span>), «ലേക്ക്» (<span class="ar">إلى</span>), «ആകുന്നു» |

<div class="rule-box">
  <strong>അർത്ഥവ്യാപ്തി പ്രകാരം മുഫ്രദ്:</strong><br/>
  • <strong>ജുസ്ഈ (جزئي):</strong> ഒന്നിലധികം ആളുകളിൽ ഒന്നിച്ചു പങ്കുചേരാൻ മനസ്സ് സമ്മതിക്കാത്ത നിശ്ചിത പദം (സൈദ്, ഈ പുസ്തകം, മക്ക).<br/>
  • <strong>കുല്ലി (كلي):</strong> ഒന്നിലധികം വ്യക്തികൾക്ക് ഒരേസമയം യോജിക്കുന്നത് (മനുഷ്യൻ, ജീവി).<br/>
  &nbsp;&nbsp;— <strong>മുതവാത്വിഅ് (متواطئ):</strong> വ്യക്തികളിൽ തുല്യമായി പുലരുന്നത് (മനുഷ്യൻ - സൈദിലും അംറിലും ഒരേപോലെ).<br/>
  &nbsp;&nbsp;— <strong>മുശക്കക് (مشكك):</strong> വ്യക്തികളിൽ ഏറ്റക്കുറച്ചിലോടെ പുലരുന്നത് (പ്രകാശം - സൂര്യനിലും വിളക്കിലും; അസ്തിത്വം - സ്രഷ്ടാവിലും സൃഷ്ടിയിലും).<br/>
  • <strong>ബഹുമുഖ പദങ്ങൾ:</strong> <strong>മുശ്തരക് (مشترك):</strong> ഒരേ പദം ഒന്നിലധികം അർത്ഥങ്ങൾക്ക് വെവ്വേറെ നിശ്ചയിച്ചത് (ഉദാ: <span class="ar">«عين»</span> - കണ്ണ്, നീരുറവ, സ്വർണ്ണം). | <strong>മൻഖൂൽ (منقول):</strong> ഒരു അർത്ഥത്തിൽ നിന്ന് മാറ്റപ്പെട്ടത് (ഉർഫി, ശർഈ: സ്വലാത്ത്, ഇസ്ത്വിലാഹി: ഫില്). | <strong>ഹഖീഖത്ത് & മജാസ്:</strong> യഥാർത്ഥ അർത്ഥവും സാദൃശ്യ അർത്ഥവും (സിംഹം $\rightarrow$ മൃഗം / ധീരൻ).
</div>

      <tr><td><strong>തസാവീ (تساوٍ)</strong></td><td>$A = B$</td><td>രണ്ടും ഒരേ വ്യക്തികളിൽ തുല്യം.<br/>ഉദാ: മനുഷ്യനും ചിന്താശേഷിയുള്ളവനും.</td></tr>
      <tr><td><strong>തബായുൻ (تباين)</strong></td><td>$A \cap B = \emptyset$</td><td>ഒരിക്കലും ഒന്നിച്ചു ചേരില്ല.<br/>ഉദാ: മനുഷ്യനും കുതിരയും; കല്ലും ജീവിയും.</td></tr>
      <tr><td><strong>ഉമൂം-ഖുസൂസ് മുത്വ്ലഖ്</strong></td><td>$A \subset B$</td><td>ഒന്ന് മറ്റൊന്നിനേക്കാൾ പൂർണ്ണമായും വിശാലം.<br/>ഉദാ: ജീവിയും മനുഷ്യനും (എല്ലാ മനുഷ്യരും ജീവിയാണ്).</td></tr>
      <tr><td><strong>ഉമൂം-ഖുസൂസ് മിൻ വജ്ഹ്</strong></td><td>$A \cap B \neq \emptyset$</td><td>ചിലതിൽ ഒന്നിക്കും, ചിലതിൽ വേർപിരിയും.<br/>ഉദാ: മനുഷ്യനും വെളുത്തവനും.</td></tr>
    </table>
  </div>

## 5. മുഅർരിഫ് / നിർവചനം (المعرِّف - القول الشارح)

| നിർവചന വിഭാഗം | ഘടകങ്ങൾ | ഉദാഹരണം (മനുഷ്യന്) | ഗുണനിലവാരം |
| :--- | :--- | :--- | :--- |
| **ഹദ്ദ് താം (حد تام)** | ജിൻസ് ഖരീബ് + ഫസ്ൽ ഖരീബ് | <span class="ar">«حيوان ناطق»</span> (ബുദ്ധിയുള്ള ജീവി) | ഏറ്റവും സമ്പൂർണ്ണവും ഉത്കൃഷ്ടവുമായ നിർവചനം |
| **ഹദ്ദ് നാഖിസ് (حد ناقص)** | ജിൻസ് ബഈദ് + ഫസ്ൽ ഖരീബ് (അല്ലെങ്കിൽ ഫസ്ൽ മാത്രം) | <span class="ar">«جسم نامٍ ناطق»</span> (വളരുന്ന ബുദ്ധിയുള്ള വസ്തു) / «നാതിഖ്» | സത്തയെ വേർതിരിക്കും, പൂർണ്ണത കുറയും |
| **റസ്മ് താം (رسم تام)** | ജിൻസ് ഖരീബ് + ഖാസ്വ | <span class="ar">«حيوان ضاحك»</span> (ചിരിക്കുന്ന ജീവി) / എഴുതുന്ന ജീവി | ബാഹ്യഗുണം വെച്ചുള്ള മികച്ച നിർവചനം |
| **റസ്മ് നാഖിസ് (رسم ناقص)** | ജിൻസ് ബഈദ് + ഖാസ്വ (അല്ലെങ്കിൽ ഖാസ്വ മാത്രം) | <span class="ar">«جسم ضاحك»</span> / «ചിരിക്കുന്നവൻ» | ഏറ്റവും ലളിതമായ തിരിച്ചറിയൽ |

<div class="rule-box">
  <strong>നിർവചനത്തിന്റെ 4 അനിവാര്യ നിബന്ധനകൾ (ശർത്വുകൾ):</strong><br/>
  1. <strong>ജാമിഉം മാനിഉം (جامع ومانع):</strong> നിർവചിക്കപ്പെടുന്ന എല്ലാ വ്യക്തികളെയും ഉൾക്കൊള്ളുന്നതും അല്ലാത്തവയെ തടയുന്നതുമാവണം (മുസാവിയാവണം).<br/>
  2. <strong>വ്യക്തത (أجلى وأظهر):</strong> നിർവചിക്കപ്പെടുന്ന പദത്തേക്കാൾ അവ്യക്തമോ തുല്യ അജ്ഞാതമോ ആവരുത്.<br/>
  3. <strong>ദൗറും തസൽസുലും (الدور والتسلسل) ഒഴിവാക്കൽ:</strong> ഒന്നിനെ മനസ്സിലാക്കാൻ മറ്റൊന്നിനെ ആശ്രയിക്കുന്ന ചാക്രികത പാടില്ല (ഉദാ: «വിജ്ഞാനം എന്നാൽ അറിയപ്പെടുന്നതിനെ അറിയലാണ്»).<br/>
  4. <strong>അവ്യക്ത പദങ്ങൾ ഒഴിവാക്കൽ:</strong> വ്യക്തമായ അടയാളമില്ലാതെ ദുർഗ്രഹമായ അലങ്കാര പ്രയോഗങ്ങളോ അന്യ പദങ്ങളോ ഉപയോഗിക്കരുത്.
</div>

## 6. ഖദിയ്യ (القضية): വിധിവാക്യങ്ങൾ
> **നിർവചനം:** സ്വതവേ സത്യമോ അസത്യമോ ആകാൻ സാധ്യതയുള്ള വാക്യം (<span class="ar">قول يحتمل الصدق والكذب لذاته</span>). പ്രധാനമായും രണ്ടു തരം: **ഹംലിയ്യ** (സമ്പർക്ക വാക്യം), **ശർത്വിയ്യ** (വ്യവസ്ഥാ വാക്യം).

### A. ഖദിയ്യ ഹംലിയ്യ (القضية الحملية)
<div class="rule-box">
  <strong>ഘടകങ്ങൾ (3):</strong> 1. <strong>മൗദൂഅ് (موضوع):</strong> വിധിക്കപ്പെടുന്ന വിഷയം (Subject). 2. <strong>മഹ്മൂൽ (محمول):</strong> വിധിക്കുന്ന കാര്യം (Predicate). 3. <strong>റാബിത്വ (رابطة):</strong> അവ തമ്മിലുള്ള ബന്ധം (Copula).
</div>

**മഹ്സൂറാത്തുൽ അർബഅ് (The 4 Standard Quantified Categorical Propositions):**

| കോഡ് | പേര് (അറബി & മലയാളം) | സൂർ (سور) | പാഠപുസ്തക ഉദാഹരണം | ലോജിക്കൽ ഘടന |
| :---: | :--- | :--- | :--- | :--- |
| <span class="badge">ക.മൂ</span><br/>**م.ك** | **കുല്ലിയ്യ മൂജിബ**<br/>(موجبة كلية) | എല്ലാ, ഓരോ<br/><span class="ar">كلّ، جميع، عامة</span> | «എല്ലാ മനുഷ്യരും ജീവികളാണ്»<br/><span class="ar">«كل إنسان حيوان»</span> | എല്ലാ $S$-ഉം $P$ ആകുന്നു ($SaP$) |
| <span class="badge badge-saliba">ക.സാ</span><br/>**س.ك** | **കുല്ലിയ്യ സാലിബ**<br/>(سالبة كلية) | ഒന്നുമില്ല, ആരുമില്ല<br/><span class="ar">لا شيء، لا أحد</span> | «ഒരു മനുഷ്യനും കല്ലല്ല»<br/><span class="ar">«لا شيء من الإنسان بحجر»</span> | ഒരു $S$-ഉം $P$ അല്ല ($SeP$) |
| <span class="badge">ജ.മൂ</span><br/>**م.ج** | **ജുസ്ഇയ്യ മൂജിബ**<br/>(موجبة جزئية) | ചില, ചിലത്<br/><span class="ar">بعض، واحد</span> | «ചില മനുഷ്യർ എഴുത്തുകാരാണ്»<br/><span class="ar">«بعض الإنسان كاتب»</span> | ചില $S$, $P$ ആകുന്നു ($SiP$) |
| <span class="badge badge-saliba">ജ.സാ</span><br/>**س.ج** | **ജുസ്ഇയ്യ സാലിബ**<br/>(سالبة جزئية) | ചിലതല്ല, എല്ലാം... അല്ല<br/><span class="ar">ليس بعض، ليس كل</span> | «ചില മനുഷ്യർ എഴുത്തുകാരല്ല»<br/><span class="ar">«ليس بعض الإنسان بكاتب»</span> | ചില $S$, $P$ അല്ല ($SoP$) |

<div class="rule-box">
  • <strong>ശഖ്സിയ്യ / മഖ്സൂസ (شخصية / مخصوصة):</strong> മൗദൂഅ് ഒരു പ്രത്യേക വ്യക്തിയാകുന്നത് (ഉദാ: «സൈദ് പണ്ഡിതനാണ്»).<br/>
  • <strong>മുഹ്‌മല (مهملة):</strong> സൂർ വ്യക്തമാക്കാത്തത് (ഉദാ: «മനുഷ്യൻ നഷ്ടത്തിലാണ്»). ഇത് പ്രയോഗത്തിൽ <em>ജുസ്ഇയ്യക്ക്</em> തുല്യമാണ്.
</div>

### B. ഖദിയ്യ മഅ്ദൂലയും മുഹസ്വലയും (المعدولة والمحصلة)

| ഇനം | നിർവചനം | ഉദാഹരണം | വ്യത്യാസം / നിയമം |
| :--- | :--- | :--- | :--- |
| **മുഹസ്വല (محصلة)** | കക്ഷികളിൽ നിഷേധ പദമില്ലാത്തത്. | «സൈദ് ജീവനുള്ളവനാണ്» | സാധാരണ വാക്യം. |
| **മഅ്ദൂലത്തുൽ മൗദൂഅ്** | മൗദൂഇന്റെ ഭാഗമായി നിഷേധം ചേരുന്നത്. | «അജീവിയായ വസ്തു നിർജ്ജീവമാണ്» (<span class="ar">اللاحي جماد</span>) | **സാലിബയും മഅ്ദൂലയും തമ്മിലെ വ്യത്യാസം:** സാലിബയിൽ നിസ്ബത്തിനെ (ബന്ധത്തെ) പൂർണ്ണമായി നിഷേധിക്കുന്നു. |
| **മഅ്ദൂലത്തുൽ മഹ്മൂൽ** | മഹ്മൂലിന്റെ ഭാഗമായി നിഷേധം ചേരുന്നത്. | «സൈദ് കാഴ്ചയില്ലാത്തവനാണ് (ലാ-ബസ്വീർ)» | മഅ്ദൂലയിലാകട്ടെ, നിഷേധം ചേർത്ത ഒരു പദത്തെ വിഷയത്തിൽ സ്ഥിരപ്പെടുത്തുകയാണ് (ഇത് മൂജിബയാണ്). |
| **മഅ്ദൂലത്തുത്ത്വറഫയ്ൻ** | രണ്ട് ഭാഗത്തും നിഷേധ പദം ചേരുന്നത്. | «അജീവിയായ വസ്തു അറിവില്ലാത്തതാണ്» | രണ്ട് ഭാഗത്തും നിഷേധം ചേർന്നാലും വാക്യം മൂജിബയായി പരിഗണിക്കപ്പെടാം. |

### C. ഖദിയ്യ ശർത്വിയ്യ (القضية الشرطية)
> രണ്ട് വാക്യങ്ങൾക്കിടയിൽ ബന്ധമോ വേർപിരിയലോ കൽപ്പിക്കുന്ന വാക്യം. ആദ്യ ഭാഗം **മുഖദ്ദമ് (مقدم)**, രണ്ടാം ഭാഗം **താലി (تالي)**.

| വിഭാഗം | ഉപവിഭാഗം & സ്വഭാവം | ഉദാഹരണം | ലോജിക്കൽ വിധി |
| :--- | :--- | :--- | :--- |
| **മുത്തസ്വില (متصلة)**<br/><small>നിബന്ധനയും ഫലവും തമ്മിലെ ബന്ധം</small> | **ലുസൂമിയ്യ (لزومية):** ആന്തരിക കാര്യകാരണ ബന്ധത്താൽ നിർബന്ധമാകുന്നത്. | «സൂര്യൻ ഉദിച്ചിട്ടുണ്ടെങ്കിൽ പകലുണ്ട്» | മുഖദ്ദമ് താലിയെ അനിവാര്യമാക്കുന്നു. |
| | **ഇത്വിഫാഖിയ്യ (اتفاقية):** കാര്യകാരണ ബന്ധമില്ലാതെ ആകസ്മികമായി യോജിക്കുന്നത്. | «മനുഷ്യൻ സംസാരിക്കുന്നവനാണെങ്കിൽ കുതിര ചിനയ്ക്കും» | ബാഹ്യ യാദൃശ്ചികത മാത്രം. |
| **മുൻഫസ്വില (منفصلة)**<br/><small>കക്ഷികൾ തമ്മിലുള്ള വൈരുദ്ധ്യവും വേർപിരിയലും</small> | **മാനിഅത്തുൽ ജംഇ വൽ ഖുലുവ്വ് (مانعة الجمع والخلو):** ഒന്നിച്ചു കൂടുകയോ ഇല്ലാതാവുകയോ ഇല്ല (ഹഖീഖിയ്യ). | «ഈ സംഖ്യ ഒന്നുകിൽ ഇരട്ട അല്ലെങ്കിൽ ഒറ്റ» | ഒന്ന് നിർബന്ധമായും സത്യം, മറ്റേത് അസത്യം. |
| | **മാനിഅത്തുൽ ജംഅ് മാത്രം (مانعة الجمع فقط):** ഒന്നിച്ചു കൂടില്ല, എന്നാൽ ഒന്നിച്ചില്ലാതായേക്കാം. | «ഈ വസ്തു ഒന്നുകിൽ കറുപ്പ് അല്ലെങ്കിൽ വെളുപ്പ്» | രണ്ടും ഒന്നിച്ചു വരില്ല (മഞ്ഞയോ പച്ചയോ ആകാം). |
| | **മാനിഅത്തുൽ ഖുലുവ്വ് മാത്രം (مانعة الخلو فقط):** ഒന്നിച്ചില്ലാതാവില്ല, എന്നാൽ ഒന്നിച്ചു കൂടിയേക്കാം. | «സൈദ് ഒന്നുകിൽ കടലിലല്ല, അല്ലെങ്കിൽ അവൻ മുങ്ങാത്തവനാണ്» | ഏതെങ്കിലും ഒന്നുണ്ടാകൽ നിർബന്ധം. |

## 7. മുവജ്ജഹാത്ത് (القضايا الموجهة - Modality Engine)

<div class="rule-box">
  • <strong>മാദ്ദത്ത് (مادة):</strong> വിഷയവും ഗുണവും തമ്മിൽ യാഥാർത്ഥ്യത്തിലുള്ള അനിവാര്യത (വുജൂബ്, ഇംതിനാഅ്, ഇംകാൻ).<br/>
  • <strong>ജിഹത്ത് (جهة):</strong> വാക്യത്തിൽ പ്രകടമായി പറയുന്ന മോഡൽ പദം (നിർബന്ധമായും, ശാശ്വതമായി, സാധ്യതയോടെ...).
</div>

| മുവജ്ജഹ ബസീത്വ (ലളിതം) | വിവക്ഷ / ശർത്വ് | ഉദാഹരണം |
| :--- | :--- | :--- |
| **ദറൂരിയ്യ മുത്വ്ലഖ (ضرورية مطلقة)** | സത്താപരമായി നിലനിൽക്കുന്നേടത്തോളം അനിവാര്യം. | «ദൈവം നിർബന്ധമായും ജീവനുള്ളവനാണ്», «മനുഷ്യൻ ജീവിയാകൽ അനിവാര്യമാണ്» |
| **ദാഇമ മുത്വ്ലഖ (دائمة مطلقة)** | സത്ത നിലനിൽക്കുന്ന കാലമത്രയും ശാശ്വതമായിരിക്കും. | «എല്ലാ നക്ഷത്രങ്ങളും ശാശ്വതമായി ചലിക്കുന്നവയാണ്» |
| **മശ്റൂത്വ ആമ്മ (مشروطة عامة)** | മൗദൂഇന്റെ പ്രത്യേക വിശേഷണം ഉള്ള കാലത്തോളം അനിവാര്യം. | «എഴുതുന്നയാൾ എഴുതുന്ന കാലമത്രയും വിരലനക്കൽ അനിവാര്യമാണ്» |
| **ഉർഫിയ്യ ആമ്മ (عرفية عامة)** | മൗദൂഇന്റെ പ്രത്യേക വിശേഷണം ഉള്ള കാലത്തോളം ശാശ്വതം. | «എഴുതുന്നയാൾ എഴുതുന്നിടത്തോളം വിരലനക്കൽ ശാശ്വതമാണ്» |
| **വഖ്തിയ്യ മുത്വ്ലഖ (وقتية مطلقة)** | നിശ്ചിതമായ ഒരു പ്രത്യേക സമയത്ത് അനിവാര്യം. | «ചന്ദ്രൻ ഗ്രഹണ സമയത്ത് മറയപ്പെടൽ അനിവാര്യമാണ്» |
| **മുന്തശിറ മുത്വ്ലഖ (منتشرة مطلقة)** | നിശ്ചിതമല്ലാത്ത ഏതെങ്കിലും സമയത്ത് അനിവാര്യം. | «രോഗിക്ക് ചില പ്രത്യേക ഘട്ടത്തിൽ വിയർക്കൽ അനിവാര്യമാണ്» |
| **മുംകിന ആമ്മ (ممكنة عامة)** | എതിർവശം അസംഭവ്യമല്ല (വിരുദ്ധം അനിവാര്യമല്ല). | «തീയിൽ വിറക് കത്തൽ സാധ്യമാണ്» |
| **മുത്വ്ലഖ ആമ്മ / ഫിലിയ്യ (مطلقة عامة)** | കാര്യം യഥാർത്ഥത്തിൽ സംഭവിച്ചിട്ടുണ്ട് (ഫില്). | «എല്ലാ മനുഷ്യരും ശ്വാസമെടുക്കുന്നു» |

<div class="rule-box">
  <strong>മുവജ്ജഹാത്ത് മുറക്കബ (സംയുക്ത മോഡലുകൾ - ഒരു പോസിറ്റീവും ഒരു നെഗറ്റീവും ചേർന്നത്):</strong><br/>
  1. <strong>മശ്റൂത്വ ഖാസ്വ (مشروطة خاصة):</strong> മശ്റൂത്വ ആമ്മ + വിശേഷണം പോയാൽ ശാശ്വതമല്ല എന്ന നിബന്ധന. | 2. <strong>ഉർഫിയ്യ ഖാസ്വ (عرفية خاصة):</strong> ഉർഫിയ്യ ആമ്മ + ദാതിയായി ശാശ്വതമല്ലെന്ന നിബന്ധന. | 3. <strong>മുംകിന ഖാസ്വ (ممكنة خاصة):</strong> വുജൂബും ഇംതിനാഉം ഇല്ലാത്തത് (രണ്ടു ഭാഗത്തേക്കും തുല്യ സാധ്യത).
</div>

## 8. തനാഖുദ് (التناقض - Contradiction)
> **നിർവചനം:** രണ്ട് ഖദിയ്യകൾ തമ്മിൽ ഇജ്ജാബിലും സൽബിലും വ്യത്യാസപ്പെടുകയും, അതിനാൽ തന്നെ ഒന്ന് സത്യമാകുമ്പോൾ മറ്റേത് നിർബന്ധമായും അസത്യമാവുകയും ചെയ്യുക (<span class="ar">اختلاف قضيتين بالإيجاب والسلب بحيث يقتضي لذاته صدق إحداهما وكذب الأخرى</span>).

<div class="rule-box">
  <strong>തനാഖുദിന്റെ നിബന്ധനകൾ — വഹ്ദാത്തുകൾ (الوحدات الثمان / العشر):</strong><br/>
  രണ്ടു വാക്യങ്ങൾ തമ്മിൽ വൈരുദ്ധ്യമുണ്ടാകാൻ 8 കാര്യങ്ങളിൽ ഐക്യം നിർബന്ധമാണ്: 
  <strong>1. മൗദൂഅ്</strong> (വിഷയം ഒന്നാവണം) | <strong>2. മഹ്മൂൽ</strong> (വിധിക്കുന്ന കാര്യം ഒന്നാവണം) | <strong>3. സമാൻ</strong> (സമയം ഒന്നാവണം) | <strong>4. മക്കാൻ</strong> (സ്ഥലം ഒന്നാവണം) | <strong>5. ശർത്വ്</strong> (വ്യവസ്ഥ ഒന്നാവണം) | <strong>6. ഇദാഫത്ത്</strong> (ബന്ധം ഒന്നാവണം) | <strong>7. കുല്ലും ജുസ്ഉം</strong> (പൂർണ്ണത/ഭാഗികത ഒന്നാവണം) | <strong>8. ഖുവ്വത്തും ഫില്ഉം</strong> (പ്രാപ്തിയും പ്രവൃത്തിയും ഒന്നാവണം). <em>(മുവജ്ജഹാത്തിൽ ജിഹത്തും ഒന്നാവണം).</em>
</div>

### മഹ്സൂറാത്തുൽ അർബഇന്റെ തനാഖുദ് നിയമം (The Golden Cross)

| യഥാർത്ഥ വാക്യം (الأصل) | ബന്ധം | അതിന്റെ നഖീദ് (النقيض) | നിയമം & വ്യാഖ്യാനം |
| :--- | :---: | :--- | :--- |
| **ക.മൂ (موجبة كلية)**<br/>«എല്ലാ മനുഷ്യരും ജീവികളാണ്» | $\iff$ | **ജ.സാ (سالبة جزئية)**<br/>«ചില മനുഷ്യർ ജീവികളല്ല» | കമ്മിലും (കുല്ല് $\leftrightarrow$ ജുസ്അ്) കയ്ഫിലും (മൂജിബ $\leftrightarrow$ സാലിബ) വ്യത്യാസപ്പെടണം. ഒന്ന് സത്യമായാൽ മറ്റേത് കള്ളമാകും. |
| **ക.സാ (سالبة كلية)**<br/>«ഒരു മനുഷ്യനും കല്ലല്ല» | $\iff$ | **ജ.മൂ (موجبة جزئية)**<br/>«ചില മനുഷ്യർ കല്ലാണ്» | കമ്മിലും കയ്ഫിലും വ്യത്യാസപ്പെടണം. |
| **മഖ്സൂസ മൂജിബ**<br/>«സൈദ് എഴുത്തുകാരനാണ്» | $\iff$ | **മഖ്സൂസ സാലിബ**<br/>«സൈദ് എഴുത്തുകാരനല്ല» | മഖ്സൂസകളിൽ കമ്മില്ലാത്തതിനാൽ കയ്ഫിൽ (ഇജ്ജാബ്/സൽബ്) മാത്രം വ്യത്യാസപ്പെട്ടാൽ മതിയാകും. |

<div class="rule-box">
  <strong>മുവജ്ജഹാത്തിലെ നഖീദ് സൂത്രവാക്യം:</strong><br/>
  • <strong>ദറൂരിയ്യ (ضرورية)</strong> യുടെ നഖീദ് $\rightarrow$ <strong>മുംകിന ആമ്മ (ممكنة عامة)</strong> ആയിരിക്കും.<br/>
  • <strong>ദാഇമ (دائمة)</strong> യുടെ നഖീദ് $\rightarrow$ <strong>മുത്വ്ലഖ ആമ്മ (مطلقة عامة)</strong> ആയിരിക്കും. (കയ്ഫും കമ്മിന്റെ മാറ്റവും ഒപ്പം ബാധകമാണ്).
</div>

## 9. അക്സുൽ മുസ്തവീ (العكس المستوي - Simple Conversion)
> **നിർവചനം:** സത്യതയും (സിദ്ഖ്) ഇജ്ജാബ്/സൽബും (കയ്ഫ്) അതേപടി നിലനിർത്തിക്കൊണ്ട് മൗദൂഇനെ മഹ്മൂലിന്റെ സ്ഥാനത്തും, മഹ്മൂലിനെ മൗദൂഇന്റെ സ്ഥാനത്തും പരസ്പരം മാറ്റിവെക്കൽ (<span class="ar">تبديل طرفي القضية مع بقاء الصدق والكيف بحالهما</span>).

| യഥാർത്ഥ വാക്യം | അക്സ് (പ്രതിവർത്തനം) | ഉദാഹരണം | ലോജിക്കൽ കാരണവും നിയമവും |
| :---: | :---: | :--- | :--- |
| <span class="badge">ക.മൂ</span><br/>**കുല്ലിയ്യ മൂജിബ** | <span class="badge">ജ.മൂ</span><br/>**ജുസ്ഇയ്യ മൂജിബ** | «എല്ലാ മനുഷ്യരും ജീവികളാണ്»<br/>$\Downarrow$<br/><strong>«ചില ജീവികൾ മനുഷ്യരാണ്»</strong> | ക.മൂ ആയിത്തന്നെ തിരിക്കാൻ കഴിയില്ല; കാരണം മഹ്മൂൽ കൂടുതൽ വിശാലമായാൽ (ഉമൂം-ഖുസൂസ് മുത്വ്ലഖ്) സത്യം നിലനിൽക്കില്ല («എല്ലാ ജീവികളും മനുഷ്യരാണ്» എന്ന് പറയാൻ കഴിയില്ല). അതിനാൽ <strong>ജ.മൂ</strong> ആയി ചുരുങ്ങുന്നു. |
| <span class="badge badge-saliba">ക.സാ</span><br/>**കുല്ലിയ്യ സാലിബ** | <span class="badge badge-saliba">ക.സാ</span><br/>**കുല്ലിയ്യ സാലിബ** | «ഒരു മനുഷ്യനും കല്ലല്ല»<br/>$\Downarrow$<br/><strong>«ഒരു കല്ലും മനുഷ്യനല്ല»</strong> | രണ്ട് കക്ഷികളും പൂർണ്ണമായി പരസ്പരം അകന്നുനിൽക്കുന്നതിനാൽ (തബായുൻ) അതേപടി കുല്ലിയ്യ സാലിബയായിത്തന്നെ തിരിയും. |
| <span class="badge">ജ.മൂ</span><br/>**ജുസ്ഇയ്യ മൂജിബ** | <span class="badge">ജ.മൂ</span><br/>**ജുസ്ഇയ്യ മൂജിബ** | «ചില മനുഷ്യർ എഴുത്തുകാരാണ്»<br/>$\Downarrow$<br/><strong>«ചില എഴുത്തുകാർ മനുഷ്യരാണ്»</strong> | ഭാഗിക യോജിപ്പ് ഇരുവശത്തും തുല്യമായി പുലരുന്നതിനാൽ ജുസ്ഇയ്യ മൂജിബയായി തിരിയുന്നു. |
| <span class="badge badge-saliba">ജ.സാ</span><br/>**ജുസ്ഇയ്യ സാലിബ** | <span class="badge badge-saliba" style="background:#475569; color:#fff;">അക്സില്ല</span><br/>**(لا عكس لها)** | «ചില ജീവികൾ മനുഷ്യരല്ല»<br/>$\Downarrow$<br/><strong>പ്രതിവർത്തനം സാധ്യമല്ല!</strong> | ഇതിനെ തിരിച്ചിട്ട് «ചില മനുഷ്യർ ജീവികളല്ല» എന്ന് പറഞ്ഞാൽ അത് ശുദ്ധ അസത്യമാകും. സിദ്ഖ് നിലനിൽക്കാത്തതിനാൽ ജുസ്ഇയ്യ സാലിബക്ക് അക്സ് മുസ്തവീ ഇല്ല. |

## 10. അക്സുൻ നഖീദ് (عكس النقيض - Contraposition)

<div class="rule-box">
  <strong>രണ്ട് രീതികൾ:</strong><br/>
  1. <strong>അക്സുൻ നഖീദ് മുവാഫിഖ് (الموافق):</strong> ഇരു കക്ഷികളുടെയും നഖീദുകളെ (വിരുദ്ധങ്ങളെ) പരസ്പരം മാറ്റുക, കയ്ഫ് (മൂജിബ/സാലിബ) മാറ്റമില്ലാതെ നിലനിർത്തുക.<br/>
  2. <strong>അക്സുൻ നഖീദ് മുഖാലിഫ് (المخالف):</strong> മൗദൂഇന്റെ സ്ഥാനത്ത് മഹ്മൂലിന്റെ നഖീദും, മഹ്മൂലിന്റെ സ്ഥാനത്ത് മൗദൂഇന്റെ ഐനും (യഥാർത്ഥ രൂപവും) വെക്കുക, കയ്ഫിൽ വ്യത്യാസം വരുത്തുക.
</div>

| യഥാർത്ഥ വാക്യം | മുവാഫിഖ് (الموافق) | മുഖാലിഫ് (المخالف) | ഉദാഹരണം (മുവാഫിഖ്) |
| :--- | :---: | :---: | :--- |
| **ക.മൂ (موجبة كلية)** | **ക.മൂ (م.ك)** | **ക.സാ (س.ك)** | «എല്ലാ മനുഷ്യരും ജീവിയാണ്» $\rightarrow$ «ജീവിയല്ലാത്തതൊന്നും മനുഷ്യനല്ല» |

## 14. ഖിയാസ് ഇസ്തിസ്നാഈ (القياس الاستثنائي)
> നതീജയോ അതിന്റെ വിരുദ്ധമോ മുഖദ്ദിമയിൽ നേരിട്ട് «പക്ഷേ» (<span class="ar">لكن</span>) എന്ന ഇസ്തിസ്നാഇന്റെ അക്ഷരത്തോടെ എടുത്തുപറയുന്ന രീതി.

<div class="grid-2">
  <div class="rule-box">
    <strong>A. ശർത്വിയ്യ മുത്തസ്വിലയിലെ നിയമം (2 മുന്തജ്):</strong><br/>
    1. <strong>വദ്ഉൽ മുഖദ്ദം $\rightarrow$ വദ്ഉത്താലി:</strong> മുഖദ്ദമിനെ സ്ഥിരപ്പെടുത്തിയാൽ താലി സ്ഥിരപ്പെടും.<br/>
    <em>«സൂര്യനുദിച്ചാൽ പകലുണ്ട്; പക്ഷേ സൂര്യനുദിച്ചു $\rightarrow$ അതിനാൽ പകലുണ്ട്.»</em><br/>
    2. <strong>റഫ്ഉത്താലി $\rightarrow$ റഫ്ഉൽ മുഖദ്ദം:</strong> താലിയെ നിഷേധിച്ചാൽ മുഖദ്ദമ് നിഷേധിക്കപ്പെടും.<br/>
    <em>«സൂര്യനുദിച്ചാൽ പകലുണ്ട്; പക്ഷേ പകലില്ല $\rightarrow$ അതിനാൽ സൂര്യനുദിച്ചിട്ടില്ല.»</em><br/>
    <small style="color:#b91c1c;">(ശ്രദ്ധിക്കുക: താലിയെ സ്ഥിരപ്പെടുത്തലോ മുഖദ്ദമിനെ നിഷേധിക്കലോ യാതൊന്നും ഉത്പാദിപ്പിക്കില്ല).</small>
  </div>
  <div class="rule-box">
    <strong>B. ശർത്വിയ്യ മുൻഫസ്വിലയിലെ നിയമങ്ങൾ:</strong><br/>
    1. <strong>മാനിഅത്തുൽ ജംഇ വൽ ഖുലുവ്വ് (4 മുന്തജ്):</strong> ഒന്നിന്റെ വദ്അ് മറ്റേതിന്റെ റഫ്ഇനെയും, ഒന്നിന്റെ റഫ്അ് മറ്റേതിന്റെ വദ്ഇനെയും അനിവാര്യമാക്കും.<br/>
    <em>(സംഖ്യ ഇരട്ടയാണ് $\rightarrow$ ഒറ്റയല്ല; ഇരട്ടയല്ല $\rightarrow$ ഒറ്റയാണ്).</em><br/>
    2. <strong>മാനിഅത്തുൽ ജംഅ് (2 മുന്തജ്):</strong> ഒന്നിന്റെ വദ്അ് മറ്റേതിന്റെ റഫ്ഇനെ മാത്രം നൽകും.<br/>
    3. <strong>മാനിഅത്തുൽ ഖുലുവ്വ് (2 മുന്തജ്):</strong> ഒന്നിന്റെ റഫ്അ് മറ്റേതിന്റെ വദ്ഇനെ മാത്രം നൽകും.
  </div>
</div>

## 15. അനുമാനത്തിന്റെ ഇതര ശാഖകൾ: ഇസ്തിഖ്റാഉം തംസിലും

| ശാഖ | നിർവചനം | ഇനങ്ങൾ / ഘടകങ്ങൾ | വിജ്ഞാനപരമായ പദവി |
| :--- | :--- | :--- | :--- |
| **ഇസ്തിഖ്റാഅ് (الاستقراء)**<br/><small>Induction / നിരീക്ഷണം</small> | വ്യക്തിഗത വിവരങ്ങൾ വിശദമായി പരിശോധിച്ച് ഒരു പൊതു വിധിയിലെത്തൽ. | • <strong>താം (സമ്പൂർണ്ണം):</strong> എല്ലാ വ്യക്തികളെയും പൂർണ്ണമായി എണ്ണിത്തിട്ടപ്പെടുത്തിയത്.<br/>• <strong>നാഖിസ് (അപൂർണ്ണം):</strong> ചിലതിനെ മാത്രം കണ്ട് പൊതുവിധി കൽപ്പിക്കൽ. | താം ആയത് <strong>യഖീനി (ഖണ്ഡിതം)</strong> ആണ്. നാഖിസ് ആയത് <strong>ളന്നീ (സാധ്യത മാത്രം)</strong> ആണ്. |
| **തംസീൽ (التمثيل)**<br/><small>Analogy / സാദൃശ്യം (ഖിയാസ് ഫിഖ്ഹീ)</small> | ഒരു പൊതുവായ കാരണം (ഇല്ലത്ത്) നിമിത്തം ഒരു കാര്യത്തിലെ വിധി സമാനമായ മറ്റൊന്നിലേക്ക് പകർത്തൽ. | <strong>നാല് അർകാനുകൾ:</strong><br/>1. അസ്ൽ (അടിസ്ഥാനം: മദ്യം)<br/>2. ഫർഅ് (ശാഖ: ലഹരിയുള്ള ലഹരിവസ്തു)<br/>3. ജാമിഅ് / ഇല്ലത്ത് (കാരണം: ലഹരി)<br/>4. ഹുക്മ് (വിധി: ഹറാം) | ഇത് <strong>ളന്നിയായ (സാധ്യതയുള്ള)</strong> അറിവ് മാത്രമേ നൽകൂ. ബുർഹാനായി പരിഗണിക്കില്ല. |

## 16. സനാഇഉൽ ഖംസ് (الصناعات الخمس - വാദങ്ങളുടെ പൊരുളും 5 കലകളും)
> ഖിയാസിന്റെ ഘടന (രൂപം) ശരിയായാലും അതിലുപയോഗിക്കുന്ന മുഖദ്ദിമകളുടെ യാഥാർത്ഥ്യത്തെയും (മാദ്ദത്ത്) ഉദ്ദേശ്യത്തെയും അടിസ്ഥാനമാക്കി വാദങ്ങളെ അഞ്ചായി തിരിക്കുന്നു:

| കല | ആശ്രയിക്കുന്ന മുഖദ്ദിമകൾ (വിജ്ഞാന ഉറവിടങ്ങൾ) | ഉദ്ദേശ്യവും ലക്ഷ്യവും | ഫലം / വിജ്ഞാന പദവി |
| :--- | :--- | :--- | :--- |
| **1. ബുർഹാൻ<br/>(البرهان)** | <strong>യഖീനിയ്യാത്തുകൾ (اليقينيات)</strong> മാത്രം ആശ്രയിക്കുന്നു. സന്ദേഹമില്ലാത്ത ആറ് അടിസ്ഥാനങ്ങൾ (താഴെ കാണുക). | സത്യം സ്ഥാപിക്കലും സംശയലേശമന്യേ ബോധ്യപ്പെടുത്തലും. | **യഖീൻ ഖത്വ്ഈ (ഖണ്ഡിതമായ സത്യം)** |
| **2. ജദൽ<br/>(الجدل)** | <strong>മശ്ഹൂറാത്ത് (مشهورات):</strong> ജനങ്ങൾ പൊതുവെ അംഗീകരിച്ച കാര്യങ്ങൾ.<br/><strong>മുസല്ലമാത്ത് (مسلمات):</strong> എതിരാളി സമ്മതിച്ച കാര്യങ്ങൾ. | എതിരാളിയെ വാദപ്രതിവാദത്തിൽ തോൽപ്പിക്കലും നിശബ്ദനാക്കലും. | പ്രബലമായ അഭിപ്രായ രൂപീകരണം (ഇൽസാമ്). |
| **3. ഖിതാബ<br/>(الخطابة)** | <strong>മഖ്ബൂലാത്ത് (مقبولات):</strong> വിശ്വസ്തരായ പണ്ഡിതർ/നേതാക്കൾ പറഞ്ഞത്.<br/><strong>മദ്നൂനാത്ത് (مظنونات):</strong> പ്രബലമായ ധാരണകൾ. | സാധാരണക്കാരെ സന്മാർഗ്ഗത്തിലേക്ക് പ്രേരിപ്പിക്കലും കർമ്മനിരതരാക്കലും. | മനസ്സിന് സംതൃപ്തിയും ഉണർവ്വും നൽകൽ. |
| **4. ശിഅർ<br/>(الشعر)** | <strong>മുഖയ്യലാത്ത് (مخيّلات):</strong> ഭാവനകളും ഉപമകളും ആലങ്കാരിക വാഗ്ധോരണികളും. | മനസ്സിൽ സന്തോഷമോ സങ്കടമോ വെറുപ്പോ സൃഷ്ടിച്ച് സ്വാധീനിക്കൽ. | വികാരത്തെ ഉണർത്തൽ (ഇൻഫിആൽ). |
| **5. സഫ്സത്വ / മുഗാലത്വ<br/>(السفسطة)** | <strong>വഹ്മിയ്യാത്ത് (وهميات):</strong> മിഥ്യാബോധങ്ങൾ.<br/><strong>മുശബ്ബഹാത്ത് (مشبهات):</strong> തെറ്റായ സാദൃശ്യ വഞ്ചനകൾ. | സത്യത്തെ അസത്യമാക്കലും കള്ളവാദങ്ങളിലൂടെ ജനങ്ങളെ വഴിതെറ്റിക്കലും. | വഞ്ചനയും ആശയക്കുഴപ്പവും (തഗ്‌ലീത്വ്). |

### ബുർഹാന്റെ ആറ് അടിസ്ഥാനങ്ങൾ — യഖീനിയ്യാത്തുസ്സിത്ത് (اليقينيات الست)

| ഇനം | നിർവചനം | ഉദാഹരണം |
| :--- | :--- | :--- |
| **1. അവ്വലിയ്യാത്ത് (أوليات)** | കക്ഷികളെ ധരിച്ചയുടൻ ബാഹ്യ തെളിവുകളില്ലാതെ അഖ്ൽ നേരിട്ട് സ്ഥിരീകരിക്കുന്നത്. | «മുഴുവൻ എന്നത് അതിന്റെ ഭാഗത്തേക്കാൾ വലുതാണ്», «ഒന്നിന് ഒരേസമയം നിലനിൽക്കാനും ഇല്ലാതിരിക്കാനും കഴിയില്ല». |
| **2. മുശാഹദാത്ത് / ഹിസ്സിയ്യാത്ത് (مشاهدات)** | ബാഹ്യ ഇന്ദ്രിയങ്ങളാലോ (പഞ്ചേന്ദ്രിയങ്ങൾ) ആന്തരിക വികാരങ്ങളാലോ നേരിട്ടറിയുന്നത്. | ബാഹ്യം: «സൂര്യൻ പ്രകാശമുള്ളതാണ്», «തീ പൊള്ളിക്കുന്നതാണ്».<br/>ആന്തരികം (വിജ്ദാനിയ്യാത്ത്): «എനിക്ക് വിശക്കുന്നു», «എനിക്ക് സന്തോഷമുണ്ട്». |
| **3. മുജർറബാത്ത് (مجربات)** | ആവർത്തിച്ചുള്ള അനുഭവവും പരീക്ഷണവും വഴി ബുദ്ധി ഉറപ്പുവരുത്തിയ നിയമങ്ങൾ. | «ചൂടുവെള്ളം ദാഹം ശമിപ്പിക്കും», «ഈ പ്രത്യേക ഔഷധം വയറുവേദന ശമിപ്പിക്കുന്നു». |
| **4. ഹദസിയ്യാത്ത് (حدسيات)** | അതീവ ശക്തമായ ഉൾക്കാഴ്ചയും മനക്കരുത്തും വഴി പെട്ടെന്ന് മനസ്സിൽ മിന്നുന്ന ഖണ്ഡിത സത്യം. | «ചന്ദ്രന്റെ പ്രകാശം സൂര്യനിൽ നിന്നാണ് (അതിന്റെ വൃദ്ധിക്ഷയങ്ങൾ നിരീക്ഷിച്ചപ്പോൾ ബോധ്യമായത്)». |
| **5. മുതവാത്തിറാത്തുകൾ (متواترات)** | കളവിനായി ഒന്നിച്ചു ചേരൽ അസംഭവ്യമായത്ര വലിയ ജനസമൂഹം തലമുറകളായി കൈമാറിയ ചരിത്ര വിവരങ്ങൾ. | «മക്ക എന്നൊരു പുണ്യനഗരമുണ്ട്», «വിശുദ്ധ ഖുർആൻ മുഹമ്മദ് നബി(സ)ക്ക് അവതരിപ്പിക്കപ്പെട്ടതാണ്». |
| **6. ഫിത്വ്രിയ്യാത്ത് (فطريات)** | ചിന്തിക്കുമ്പോൾ തന്നെ തെളിവ് മനസ്സിൽ ഒപ്പം തന്നെയുള്ള കാര്യങ്ങൾ (<span class="ar">قضايا قياساتها معها</span>). | «നാല് എന്നത് ഇരട്ട സംഖ്യയാണ്» (രണ്ട് തുല്യ ഭാഗങ്ങളായി വിഭജിക്കാം എന്ന തെളിവ് കൂടെയുണ്ട്). |
