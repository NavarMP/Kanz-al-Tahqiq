# ഉർദു നഅ്തുകൾ · Urdu Na'at & Mehfil Collection
### کلامِ نعت و منقبت · Kanz al-Taḥqīq Digital Humanities Archive

---

കേരളത്തിലെ പരമ്പരാഗത ദർസുകളിലും മഹ്ഫിലുകളിലും സദസ്സുകളിൽ ആലപിച്ചുപോരുന്ന വിശ്രുതമായ ഉർദു നഅ്തുകളുടെയും സൂഫി ഗാനങ്ങളുടെയും ഡിജിറ്റൽ സമാഹാരം.

ഇവിടെ ഓരോ കലാമും നൽകിയിട്ടുള്ളത്:
1. **മൂല ഉർദു വരികൾ (Original Urdu with Nastaliq & Tashkeel)**
2. **മലയാള ലിപി രൂപം (Sing-along Malayalam Phonetic Script)**
3. **മലയാള തർജ്ജമയും സാഹിത്യ വ്യാഖ്യാനവും (Malayalam Translation & Scholarly Commentary)**
4. **ഇംഗ്ലീഷ് പരിഭാഷ (English Translation)**
5. **ഓഡിയോ റെക്കോർഡിംഗ് കണ്ണികൾ (Archival Audio Links)**
