## 2. വെബ് ഡിസൈൻ സിസ്റ്റവും യു.ഐ ടോക്കണുകളും (Design System & UI Tokens)

* **ആർക്കിടെക്ചർ ശൈലി**: **Neo-Spiritual Brutalist Minimalism** — ഡാർക്ക് ലക്ഷ്വറി ലേഔട്ട്, ഗ്ലാസ്മോർഫിക് കാർഡുകൾ, സ്വർണ്ണ അരികുകൾ, സൂക്ഷ്മമായ ഇസ്ലാമിക ജ്യാമിതീയ പാറ്റേണുകൾ.
* **ബാക്ക്ഗ്രൗണ്ട്**: Midnight Obsidian (`#060D0A`) വിത്ത് 1% നോയിസ് ടെക്സ്ചർ.
* **കാർഡ് പ്രതലങ്ങൾ (Surfaces)**: Deep Emerald Tinted Glass (`rgba(15, 76, 58, 0.35)`) വിത്ത് $12px$ ബാക്ക്ഡ്രോപ്പ് ബ്ലർ (Backdrop Blur) & $1px$ സുവർണ്ണ ബോർഡർ (`rgba(212, 175, 55, 0.2)`).
* **ഇന്ററാക്ഷൻ ലൈറ്റിംഗ്**: കർസർ മൂവ്‌മെന്റിനനുസരിച്ച് ചലിക്കുന്ന മൃദുവായ സ്വർണ്ണ-മരതക പ്രകാശ വലയം (Radial Gradient Cursor Ambient Glow).

### COMPONENT 07: ഉസ്താദുമാരുടെ സനദ് നിര (Faculty of Sanad)
