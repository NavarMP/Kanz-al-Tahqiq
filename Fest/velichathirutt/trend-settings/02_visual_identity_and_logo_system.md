## 1. ലോഗോ സങ്കല്പവും അനാട്ടമിയും (The Logomark Concept & Anatomy)

'സ്വുഫ്ഫ ഓൺലൈൻ ദർസ്' ലോഗോ പരമ്പരാഗത ഇസ്ലാമിക വാസ്തുവിദ്യയുടെയും ആധുനിക ഡിജിറ്റൽ സിഗ്നലുകളുടെയും അത്ഭുതകരമായ ഒരു സംയോജനമാണ്. ഇതിൽ നാല് പ്രധാന പ്രതീകാത്മക ഘടകങ്ങൾ (Symbolic Layers) ഒന്നിക്കുന്നു:

```
┌──────────────────────────────────────────────────────────────────────────┐
│                      THE FOUR ICONOGRAPHIC LAYERS                        │
└────────────────────────────────────┬─────────────────────────────────────┘
         ┌───────────────────┬───────┴───────────┬───────────────────┐
         ▼                   ▼                   ▼                   ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│  1. THE MIHRAB  │ │  2. THE RIHAL   │ │ 3. FIBER LIGHT  │ │ 4. SUFFA KUFIC  │
│     (മിഹ്‌റാബ്)    │ │     (രിഹാൽ)     │ │  (പ്രകാശ രശ്മി)  │ │   (സ്വുഫ്ഫ അറബി) │
│ പള്ളിയുടെ വിശുദ്ധി │ │ കിതാബോതുന്ന പീഠം│ │ സാങ്കേതികവിദ്യ  │ │ അസ്വ്ഹാബുസ്സുഫ്ഫ│
└─────────────────┘ └─────────────────┘ └─────────────────┘ └─────────────────┘
```

1. **മിഹ്‌റാബ് ആർച്ച് (The Sacred Mihrab Arch)**:
   * പള്ളികേന്ദ്രിതമായ ദർസ് പാരമ്പര്യത്തെയും അലത്തൂർപടിയുടെ ആത്മീയ അടിത്തറയെയും പ്രതിനിധീകരിക്കുന്ന അനുഗ്രഹീത കമാനം. 
   * ഇത് തിരിഞ്ഞുനിൽക്കാനുള്ള ആത്മീയ കേന്ദ്രത്തെ (ഖിബ്‌ല) സൂചിപ്പിക്കുന്നു.
2. **തുറന്ന രിഹാലും ഗ്രന്ഥവും (The Open Rihal & Kitab)**:
   * ദർസുകളിലെ വിദ്യാർത്ഥികൾ കിതാബുകൾ വെച്ച് ഓതുന്ന മരപ്പീഠം (രിഹാൽ). 
   * വിജ്ഞാനത്തിന്റെ വിതരണവും നിഷ്കളങ്കമായ വായനയും.
3. **പ്രകാശ രശ്മിയും ഫൈബർ ഒപ്റ്റിക് പൾസും (The Luminous Ray / Data Pulse)**:
   * മിഹ്‌റാബിന്റെ മുകളിൽ നിന്നും ഉത്ഭവിക്കുന്ന സ്വർണ്ണ വെളിച്ചം താഴേക്ക് വ്യാപിക്കുന്നത് ഒരു ഡാറ്റാ സിഗ്നലായും പ്രകാശരശ്മിയായും പരിവർത്തനം ചെയ്യപ്പെടുന്നു.
   * 'വെളിച്ചത്തിരുട്ടി'ന്റെ വ്യാജ ഇരുട്ടുകളെ ഭേദിക്കുന്ന യഥാർത്ഥ ദിവ്യവെളിച്ചം (നൂർ).
4. **'സ്വുഫ്ഫ' കൂഫി കാലിഗ്രാഫി (Stylised Kufic 'صُفَّة')**:
   * ജ്യാമിതീയ കൂഫി ശൈലിയിൽ ലോഗോയുടെ ആന്തരിക വരകൾ 'സ്വുഫ്ഫ' (صُفَّة) എന്ന അറബിക് പദത്തിന്റെ അക്ഷരരൂപങ്ങളെ സൂക്ഷ്മമായി പ്രതിഫലിപ്പിക്കുന്നു.

## 2. സേക്രഡ് ജ്യോമെട്രി & കൺസ്ട്രക്ഷൻ ഗ്രിഡ് (Sacred Geometry & Construction)

ലോഗോ മാർക്കിന്റെ നിർമ്മിതി ഗോൾഡൻ റേഷ്യോ ($\phi = 1.618$), 60 ഡിഗ്രി ഇസ്ലാമിക സമമിതി, സർക്കിൾ ഗ്രിഡ് എന്നിവയെ അടിസ്ഥാനമാക്കിയാണ് ക്രമീകരിച്ചിരിക്കുന്നത്.

```
       [4X] ───────────────┬─────────────── [4X]
                           │
                          / \  <-- 60° Sacred Angle (Triangle of Knowledge)
                         /   \
                 [R1]   /     \   [R1]
                       (   O   )  <-- Inner Circle (Golden Ratio Φ = 1.618)
                      / \     / \
                     /___\   /___\
                     \   /   \   /
                      \_/     \_/ <-- Dual Symmetrical Wings (The Open Rihal)
                       │       │
       [12X Grid] ─────┴───────┴─────────────── [Baseline]
```

* **ഗ്രിഡ് അനുപാതം**: $12 \times 12$ മോഡുലാർ ഗ്രിഡ്.
* **സ്ട്രോക്ക് തിക്നസ് (Stroke Weight)**: ബേസ് യൂണിറ്റ് $1.5X$, ഒപ്റ്റിക്കൽ ബാലൻസ് നിലനിർത്താൻ അകത്തെ ആർച്ചുകൾക്ക് $1.0X$.
* **കോണുകൾ**: കൃത്യം $45^\circ$ ഉം $60^\circ$ ഉം ആംഗിളുകൾ; യാതൊരുവിധ അപാകതകളുമില്ലാത്ത ശാസ്ത്രീയ അനുപാതം.

## 5. ടൈപ്പോഗ്രാഫി സിസ്റ്റം (Typography Hierarchy)

സ്വുഫ്ഫയുടെ ടൈപ്പോഗ്രാഫി അറബിക് ആത്മീയതയും മലയാള ഭാഷാ സൗന്ദര്യവും അന്താരാഷ്ട്ര പ്രൊഫഷണലിസവും പ്രതിഫലിപ്പിക്കുന്നു:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            TYPOGRAPHIC TRIAD                                │
├───────────────────────┬──────────────────────────┬──────────────────────────┤
│    ARABIC SCRIPT      │     MALAYALAM SCRIPT     │      LATIN / ENGLISH     │
│  Amiri & Reem Kufi    │  Manjari & Noto Serif ML │  Plus Jakarta & Garamond │
└───────────────────────┴──────────────────────────┴──────────────────────────┘
```

### 5.1. ഫോണ്ട് കുടുംബങ്ങൾ (Font Families)
1. **അറബിക് (Arabic)**:
   * **ഹെഡ്‌ലൈൻസ് & ടൈറ്റിലുകൾ**: *Reem Kufi* — ശുദ്ധമായ ജ്യാമിതീയ ശൈലി.
   * **ടെക്സ്റ്റ് & മുതൂൻ**: *Amiri (Amiri Quran)* — നസ്ഖ് ശൈലിയിലുള്ള ക്ലാസിക്കൽ അച്ചടിഭംഗി, പൂർണ്ണ തശ്‌കീൽ അനുയോജ്യം.
2. **മലയാളം (Malayalam)**:
   * **ഹെഡ്‌ലൈൻസ്**: *Manjari (Bold / Black)* — ആധുനിക ലിപി, ദൃശ്യചാരുതയും വ്യക്തതയും.
   * **ബോഡി ടെക്സ്റ്റ്**: *Gayathri (Regular)* അല്ലെങ്കിൽ *Noto Serif Malayalam* — വായനാസുഖവും ഗാംഭീര്യവും നൽകുന്ന ക്ലാസിക് ഫോണ്ട്.
3. **ഇംഗ്ലീഷ് / ലാറ്റിൻ (English / Latin)**:
   * **ഡിസ്പ്ലേ & പ്രീമിയം ഹെഡറുകൾ**: *Cormorant Garamond* — അക്കാദമിക് പ്രൗഢി.
   * **യു.ഐ & സബ് ഹെഡ്ഡുകൾ**: *Plus Jakarta Sans* — സ്ലീക്ക്, മോഡേൺ, പെർഫെക്റ്റ് ലെജിബിലിറ്റി.

### 5.2. ടൈപ്പ് സ്കെയിൽ ഹൈറാർക്കി (Type Scale Table)

### 6.1. ക്ലിയർ സ്പേസ് റൂൾ (Clear Space Rule)
ലോഗോയ്ക്ക് ചുറ്റും ലോഗോയിലെ മിഹ്‌റാബിന്റെ ഉയരത്തിന്റെ പകുതി ($0.5H$) സ്ഥലം മറ്റെല്ലാ ടെക്സ്റ്റുകളിൽ നിന്നും ചിത്രങ്ങളിൽ നിന്നും ഒഴിഞ്ഞുകിടക്കണം. ഇത് ലോഗോയുടെ ദൃശ്യഭംഗി സംരക്ഷിക്കുന്നു.

### 6.2. മിനിമം സൈസിങ് (Minimum Size)
* **ഡിജിറ്റൽ സ്ക്രീൻ (Digital UI)**: ഐക്കൺ മാത്രം: `24px x 24px`; ഫുൾ ലോക്കപ്പ്: `120px` വീതി.
* **പ്രിന്റ് മീഡിയ (Print Quality)**: ഐക്കൺ മാത്രം: `10mm x 10mm`; ഫുൾ ലോക്കപ്പ്: `35mm` വീതി.

### 6.3. കർശന നിരോധനങ്ങൾ (Misuse & Strict Don'ts)
* ❌ ലോഗോയുടെ അനുപാതം (Aspect Ratio) മാറ്റാൻ പാടില്ല (No stretching or skewing).
* ❌ അനുമതിയില്ലാത്ത നിറങ്ങൾ (Non-brand colors) ഉപയോഗിക്കാൻ പാടില്ല.
* ❌ വാചകങ്ങളുടെ സ്ഥാനമോ ഫോണ്ടോ മാറ്റാൻ പാടില്ല.
* ❌ മിഹ്‌റാബിന്റെ ആർച്ചിനെ മുറിക്കുകയോ തകിടം മറിക്കുകയോ ചെയ്യരുത്.
* ❌ കോൺട്രാസ്റ്റ് കുറഞ്ഞ ചിത്രങ്ങൾക്ക് മുകളിൽ ലോഗോ നേരിട്ട് പ്ലേസ് ചെയ്യരുത്; എപ്പോഴും ഒബ്സിഡിയൻ അല്ലെങ്കിൽ ഓഫ്-വൈറ്റ് പാച്ച് ഉപയോഗിക്കുക.
